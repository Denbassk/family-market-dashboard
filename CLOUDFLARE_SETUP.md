# Публикация дашборда с доступом по паролю (Cloudflare Pages)

Дашборд будет доступен по ссылке, но закрыт **одним общим паролем**, который ты выдаёшь
собственнику и директору. Репозиторий на GitHub остаётся **приватным**, данные не светятся
в открытом доступе. Всё бесплатно.

## Что уже готово в проекте
- `functions/_middleware.js` — «вратарь»: спрашивает логин/пароль перед показом дашборда.
- Логин фиксированный: **family**. Пароль задаётся в настройках Cloudflare (шаг 4).

## Предусловие
Проект уже залит в приватный репозиторий GitHub (скрипт `deploy.ps1`).

## Шаги (~10 минут, всё в браузере)

### 1. Регистрация
Зайди на https://dash.cloudflare.com/sign-up — заведи бесплатный аккаунт (email + пароль).

### 2. Создать проект Pages из репозитория
- В панели Cloudflare: **Workers & Pages** → **Create** → вкладка **Pages** → **Connect to Git**.
- Разреши Cloudflare доступ к GitHub, выбери приватный репозиторий `family-market-dashboard`.

### 3. Настройки сборки
Заполни так:
- **Framework preset:** None
- **Build command:** оставь пустым
- **Build output directory:** `docs`

Нажми **Save and Deploy**. Через минуту получишь ссылку вида
`https://family-market-dashboard.pages.dev`.

### 4. Задать пароль
- Открой проект → **Settings** → **Variables and Secrets** (Environment variables).
- Добавь переменную:
  - **Name:** `DASH_PASSWORD`
  - **Value:** придуманный пароль (советую 10+ символов, латиница/цифры, например `Family2026market`)
- Сохрани. Затем **Deployments** → у последнего деплоя **⋯ → Retry deployment**, чтобы пароль применился.

### 5. Проверка и раздача
- Открой ссылку `*.pages.dev` — браузер спросит логин/пароль.
  - **Логин:** `family`
  - **Пароль:** тот, что задал в шаге 4.
- Дай собственнику и директору: **ссылку + логин `family` + пароль**. Больше ничего не нужно.

## Обновление данных
GitHub Actions обновляют `docs/full_data.json` раз в сутки и пушат в репозиторий →
Cloudflare Pages автоматически переразворачивает сайт → у них всегда свежие цифры по той же ссылке.

## Сменить пароль
Настройки → Variables → измени `DASH_PASSWORD` → Retry deployment. Старый пароль сразу перестаёт работать.

---

## Если захочешь более строгую авторизацию (без общего пароля)
Вместо пароля можно включить вход по личным e-mail (одноразовый код на почту) или по Google —
через бесплатный **Cloudflare Access** (Zero Trust, до 50 пользователей бесплатно):
Zero Trust → Access → Applications → добавить приложение поверх `*.pages.dev`,
политика Allow → правило по конкретным e-mail собственника и директора.
Тогда `functions/_middleware.js` можно удалить. Это надёжнее, но им придётся вводить почту и код.
