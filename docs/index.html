Позиции

ABC — вклад в выручку (A=80% / B=15% / C=5%). XYZ — стабильность спроса: X ровный, Y колеблется, Z рваный/сезонный. Ориентир: AX — держать всегда, CZ — под заказ/вывод. Клик по строке — карточка позиции. Сортировка — клик по заголовку.

⚠ Дефицит: упущенные продажи продаётся, но остаток 0 · «есть в др. точках» = кандидат на перемещение, иначе — дозаказ

Товары без движения есть остаток, но нет продаж N дней · остаток = снимок склада, движение = по чекам

Рекомендации по перемещению только между розничными точками · клик = карточка позиции

Тепловая карта продаж день недели × час · клик по строке магазина ниже фокусирует карту · местное время

Эффективность магазинов сортируйте по любому столбцу · клик = фильтр по магазину

Оборот, дн — за сколько дней распродаётся средний остаток (меньше = лучше). Неликвид ₴ — заморожено в товарах без движения (нет продаж 90 дней). GMROI — сколько гривен валовой прибыли принесла гривна, вложенная в запас (прибыль ÷ средний остаток по себестоимости). Ниже 1,5 — деньги в этой точке работают плохо.
