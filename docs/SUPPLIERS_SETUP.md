# Вкладка «Условия поставщиков» — настройка (10 минут, один раз)

Вкладка хранит коммерческие условия в **Cloudflare KV** — это встроенное в Cloudflare
хранилище. Правки сохраняются сами, файлов больше нет, данные видны с любого компьютера
по обычной ссылке дашборда и под тем же паролем.

До настройки KV вкладка тоже работает — показывает стартовый снимок из
`docs/suppliers.json`, но **сохранять не сможет** (будет писать «⚠ не сохранено»).

---

## Шаг 1. Создать хранилище

1. Зайти в https://dash.cloudflare.com → слева **Storage & Databases** → **KV**
   (в старом интерфейсе: **Workers & Pages** → **KV**).
2. Нажать **Create a namespace** («Создать пространство имён»).
3. Имя: `family-suppliers` → **Add**.

Всё, хранилище создано. Ничего в него класть вручную не нужно.

## Шаг 2. Привязать хранилище к дашборду

1. **Workers & Pages** → проект `family-market-dashboard` → **Settings**.
2. Раздел **Bindings** (в старом интерфейсе — **Functions** → **KV namespace bindings**)
   → **Add binding**.
3. Заполнить:
   - **Variable name:** `SUPPLIERS_KV` — ровно так, заглавными, без пробелов.
     Это имя ищет код, при опечатке вкладка не сохранится.
   - **KV namespace:** выбрать `family-suppliers` из списка.
4. **Save**.

Если Cloudflare предложит выбрать окружение — добавьте привязку и в **Production**,
и в **Preview**.

## Шаг 3. Передеплоить

Привязки применяются только к новым сборкам:

**Deployments** → у верхнего деплоя меню **⋯** → **Retry deployment**.

Через минуту откройте дашборд → вкладка **«Условия поставщиков»**.
Справа в панели вкладки должно быть **☁ стартовый снимок**.
Измените что-нибудь — надпись сменится на **☁ сохранено** с временем. Готово.

---

## Как это работает

| Что | Где |
|---|---|
| Текущие данные | KV, ключ `suppliers:current` |
| Прошлые версии | KV, ключи `suppliers:v1`, `v2`, … (хранятся 90 дней) |
| Список версий | KV, ключ `suppliers:index` (последние 20) |
| Стартовый снимок | `docs/suppliers.json` в репозитории |

Правка сохраняется через 1,2 секунды после последнего нажатия клавиши.
`Ctrl+S` — сохранить немедленно. При сворачивании вкладки браузера тоже дописывается.

**Защита от потери данных, что уже встроено:**

- Пустой список поверх непустого сервер отклоняет (ошибка 409).
- Если те же данные правили из другой вкладки, сервер это заметит и спросит,
  чью версию оставить, вместо тихого затирания.
- Пропала сеть — правки остаются на экране, статус краснеет, повтор через 15 секунд.
  Уйти со страницы с несохранёнными правками браузер не даст без подтверждения.

## Лимиты бесплатного тарифа

KV даёт 100 000 чтений и **1000 записей в сутки**. Одно сохранение — это 3 записи
(данные, копия предыдущей версии, индекс), то есть примерно **330 сохранений в день**.
Для ручной правки условий это с большим запасом.

## Если что-то не так

**«⚠ не сохранено» сразу после настройки**
Откройте ссылку `<адрес дашборда>/api/suppliers` прямо в браузере.
Текст про `SUPPLIERS_KV не привязано` — значит привязка не сделана или сделана
с другим именем переменной (шаг 2), либо не передеплоили (шаг 3).

**«⚠ нет связи»**
Не отвечает сеть или сам Cloudflare. Данные на экране целы — дождитесь связи
и нажмите `Ctrl+S`.

**Нужно откатиться к прошлой версии**
Значения лежат в KV: **Storage & Databases → KV → family-suppliers → View**.
Скопируйте содержимое нужного ключа `suppliers:vN` в ключ `suppliers:current`
и обновите страницу.

**Вложения-меморандумы**
Остались в браузере (IndexedDB) и в облако не уезжают — на другом компьютере
их не будет. Сами коммерческие условия синхронизируются полностью.
