# Family Market — многостраничный дашборд ассортимента (деплой на GitHub Pages)

Трёхстраничный интерактивный дашборд по **всему ассортименту** из BigQuery:
- **Страница 1 «Обзор»** — KPI, динамика выручки/прибыли по месяцам, топ категорий, топ магазинов, сводная таблица категорий.
- **Страница 2 «Аналитика»** — ABC-анализ, оборачиваемость по категориям и магазинам, маржинальность, рейтинг магазинов, поставщики, матрица покрытия категории × магазины, неликвиды/замороженный капитал, кросс-продажи, списания.
- **Страница 3 «Перемещения»** — рекомендации: товар без продаж в одной точке (донор), но активно продаётся в другой (получатель) → что и куда переместить.

Обновляется **раз в сутки** через GitHub Actions + кнопка ручной пересборки.

## Логика данных
- **Продажи:** `turnover_transactions` за 2026, только 38 реальных магазинов (нормализация имён, слияние переименованных точек, исключение складов/просрочки).
- **Категория и поставщик:** из `assortment_matrix_full` по штрих-коду. Товары, которых нет в матрице (~7% оборота), собираются в категорию **«Прочее (нет в матрице)»** — они видны в аналитике, не теряются.
- **Оборачиваемость:** `turnover_monthly` (продажи / средний остаток), в разрезе категорий и магазинов.
- **ABC:** по всем товарам, классы A (80% выручки) / B (15%) / C (5%).

## Файлы
```
docs/index.html          дашборд (3 страницы; грузит docs/full_data.json)
docs/full_data.json      данные (стартовый снимок; дальше обновляется автоматически)
scripts/build_data.py     CI entrypoint: запускает оба сборщика и мержит результат
scripts/fetch_data.py     основные агрегаты (стр. 1-2)
scripts/fetch_page3.py    перемещения, неликвиды, кросс-продажи, списания (стр. 2-3)
requirements.txt
.github/workflows/update.yml   cron раз в сутки + ручной запуск
```

## Деплой (~5 минут)
1. **Создайте репозиторий** на https://github.com/new (можно Private).
2. **Загрузите всё содержимое пакета** (Add file → Upload files; или git push). Проверьте, что папка `.github` загрузилась.
3. **Секрет с ключом:** Settings → Secrets and variables → Actions → New repository secret. Name `GCP_SA_KEY`, Value — полное содержимое вашего service account JSON.
4. **Включите Pages:** Settings → Pages → Source «Deploy from a branch», ветка `main`, папка `/docs`. Ссылка вида `https://ВАШ_ЛОГИН.github.io/РЕПО/`.
5. **Права Actions:** Settings → Actions → General → Workflow permissions → **Read and write**.
6. **Кнопка «Обновить сейчас» (опционально):** в `docs/index.html` вверху `<script>` впишите `GH_OWNER` и `GH_REPO`. При нажатии кнопка попросит Personal Access Token (scope: Actions read/write этого репо); токен нигде не сохраняется.

## Год отчёта
Зафиксирован `REPORT_YEAR: "2026"` в `.github/workflows/update.yml`. Чтобы сменить — поменяйте значение там (или уберите строку, тогда берётся текущий год).

## Локальная проверка
```bash
pip install -r requirements.txt
export GOOGLE_APPLICATION_CREDENTIALS=/путь/к/ключу.json
REPORT_YEAR=2026 python scripts/build_data.py
python -m http.server -d docs 8000    # http://localhost:8000
```

## Изменить логику
Всё в начале `scripts/fetch_data.py`: список магазинов `NORM`, правила категорий — через матрицу. Новые метрики — добавляйте в соответствующие запросы.

## Стоимость
GitHub Pages + Actions — бесплатно. BigQuery — один запуск в сутки; следите за бесплатным лимитом сканирования 1 ТБ/мес (один прогон значительно меньше).
